# BioGreen — אתר סטטי

דף הבית של ביו-גרין, בנוי לפי:

- `מבנה דף הבית.docx` — המקור הקובע לתוכן ולסדר הבלוקים
- `BioGreen Design System.pdf` — הסקיצה, רפרנס לשפה הוויזואלית
- מערכת העיצוב שבתיקיית האב (`../tokens`, `../assets`, `../readme.md`)

התיקייה עצמאית לחלוטין — אפשר להעלות אותה כמו שהיא לכל שרת סטטי.

## הטופס

טופס אחד משרת את שלושת השערים. נפתח כמודאל, עם סוג הפנייה מסומן מראש:

- `<button data-quote data-intent="import|products|raw">` — פותח את הטופס על הסוג הזה
- `data-product="שם המוצר"` — ממלא מראש את שדה המוצר (כפתורי המוצרים עושים זאת)
- `?intent=import` בכתובת — פותח את הטופס בטעינת הדף, לקמפיינים ולינקים חיצוניים

שלב 4 בטופס מתחלף לפי סוג הפנייה (ספק כן/לא / מה מחפשים / איזה חומר גלם).

## ניהול מוצרים

כל המוצרים באתר מוגדרים בקובץ אחד: `data/products.json`. אחרי עריכה מריצים:

```bash
python tools/build-products.py
```

הסקריפט מייצר מחדש:

- שלוש הכרטיסיות בדף הבית (המוצרים עם `featured: 1/2/3`)
- כל הכרטיסיות בעמוד הקטלוג
- טאבי הסינון לפי הקטגוריות שבשימוש בפועל
- נתוני Schema.org מסוג ItemList לעמוד הקטלוג

הוא כותב **רק** בין הסימונים `<!-- products:...:start -->` ו-`<!-- products:...:end -->`
בקבצי ה-HTML; כל השאר נשאר כפי שהוא. לפני הכתיבה הוא מוודא שאין slug כפול,
שהקטגוריה קיימת, שה-tone של כל תגית חוקי ושקובץ התמונה באמת נמצא — ונעצר עם
הודעה ברורה אם לא.

**למה סקריפט ולא רינדור בדפדפן:** כל המוצרים נמצאים ב-HTML עצמו, כך שגוגל ומנועי
חיפוש מבוססי AI רואים אותם. הסינון בטאבים רק מסתיר כרטיסיות שכבר נטענו.

להסתרת מוצר בלי למחוק אותו: `"published": false`.
כשנבנה מערכת ניהול, היא תחליף את הקובץ הזה — מבנה הנתונים כבר מתאים לכך,
ו-`slug` מיועד לשמש ככתובת עמוד המוצר (`/products/<slug>/`).

## לוגואי לקוחות

הלוגואים ב-`assets/img/clients/` עברו נרמול אופטי: נחתכו לגבולות הדיו,
הומרו לגובה 160px, ומוצגים במונוכרום עם גובה מותאם לכל סימן
(`style="--logo-h:..."`), כי סימן קופסה רחב וסימן טקסט בולט לא יכולים לחלוק
גובה אחד. במעבר עכבר הם חוזרים לצבע המקורי.

להוספת לוגו חסר: שים קובץ ב-`assets/img/clients/`, והחלף את
`<span class="client__name">` ב-`<img class="client__logo" style="--logo-h:28px" src="...">`.

## הוספת עמוד חדש

כל עמוד פנימי יושב בתיקייה משלו (`products/index.html` וכו') כדי שהכתובת תהיה
`/products/` — כמו שתהיה בוורדפרס. מתוך תיקייה כזו כל הנתיבים היחסיים מקבלים
`../` (למשל `../css/site.css`).

ה-Header, ה-Footer וטופס הפנייה זהים בכל העמודים. הדרך הבטוחה להוסיף עמוד היא
להעתיק אותם מ-`index.html` ולהוסיף `../` לנתיבים, ולהעביר את `aria-current="page"`
לפריט התפריט הנכון. גם ה-sprite של האייקונים זהה בכל העמודים — אייקון חדש צריך
להתווסף לכולם.
