# BioGreen — אתר סטטי

דף הבית של ביו-גרין, בנוי לפי:

- `מבנה דף הבית.docx` — המקור הקובע לתוכן ולסדר הבלוקים
- `BioGreen Design System.pdf` — הסקיצה, רפרנס לשפה הוויזואלית
- מערכת העיצוב שבתיקיית האב (`../tokens`, `../assets`, `../readme.md`)

התיקייה עצמאית לחלוטין — אפשר להעלות אותה כמו שהיא לכל שרת סטטי.

## הטופס

טופס אחד משרת את שלושת השערים. נפתח כמודאל, עם סוג הפנייה מסומן מראש:

- `<button data-quote data-intent="import|products|raw">` — פותח את הטופס על הסוג הזה
- `data-product="שם המוצר"` — ממלא מראש את שדה המוצר (כפתורי המוצרים עושים זאת)
- `?intent=import` בכתובת — פותח את הטופס בטעינת הדף, לקמפיינים ולינקים חיצוניים

שלב 4 בטופס מתחלף לפי סוג הפנייה (ספק כן/לא / מה מחפשים / איזה חומר גלם).

## ניהול מוצרים

כל המוצרים באתר מוגדרים בקובץ אחד: `data/products.json`.

**מי שעורך דרך מערכת ניהול לא צריך להריץ כלום** — כל שינוי ב-`data/`, `tools/`
או `assets/img/` מפעיל את `.github/workflows/build.yml`, שמריץ את שלושת
הסקריפטים ועושה commit ל-HTML המחודש. האחסון פורס משם.

לעבודה מקומית מריצים ידנית:

```bash
python tools/build-products.py
```

הסקריפט מייצר מחדש:

- שלוש הכרטיסיות בדף הבית (המוצרים עם `featured: 1/2/3`)
- כל הכרטיסיות בעמוד הקטלוג
- טאבי הסינון לפי הקטגוריות שבשימוש בפועל
- נתוני Schema.org מסוג ItemList לעמוד הקטלוג

הוא כותב **רק** בין הסימונים `<!-- products:...:start -->` ו-`<!-- products:...:end -->`
בקבצי ה-HTML; כל השאר נשאר כפי שהוא. לפני הכתיבה הוא מוודא שאין slug כפול,
שהקטגוריה קיימת, שה-tone של כל תגית חוקי ושקובץ התמונה באמת נמצא — ונעצר עם
הודעה ברורה אם לא.

**למה סקריפט ולא רינדור בדפדפן:** כל המוצרים נמצאים ב-HTML עצמו, כך שגוגל ומנועי
חיפוש מבוססי AI רואים אותם. הסינון בטאבים רק מסתיר כרטיסיות שכבר נטענו.

להסתרת מוצר בלי למחוק אותו: `"published": false`.
כשנבנה מערכת ניהול, היא תחליף את הקובץ הזה — מבנה הנתונים כבר מתאים לכך,
ו-`slug` מיועד לשמש ככתובת עמוד המוצר (`/products/<slug>/`).

## עמודי מוצר

לכל מוצר שצריך עמוד משלו יוצרים `data/product-pages/<slug>.json` ומריצים:

```bash
python tools/build-product-pages.py
```

נוצר `products/<slug>/index.html`. מבנה העמוד לפי האפיון: Hero עם 6 אייקוני מוצר,
סרגל 8 טאבים (תיאור, למי מתאים, יתרונות, הוראות שימוש, רכיבים ומידע,
כשרות ואישורים, תווית, שאלות נפוצות) וטופס בקשת הצעת מחיר.

שני מקורות נתונים שמתחברים לפי ה-slug, בלי ששדה אחד יופיע בשניהם:
`products.json` מחזיק את הנתונים הקטלוגיים (שם, קטגוריה, תמונה ראשית),
ו-`product-pages/<slug>.json` את תוכן העמוד.

כשקיים קובץ עמוד למוצר, `build-products.py` מוסיף לכרטיסייה שלו בקטלוג ובדף הבית
כפתור "לפרטי המוצר". מוצר בלי קובץ עמוד מקבל רק את כפתור הצעת המחיר.

### אייקוני המוצר
ב-`assets/icons/product/`. **הכיתוב מוטמע בתוך ה-SVG כצורות וקטוריות**, ולכן:

- אין להוסיף כיתוב ב-HTML מתחת לאייקון — תיווצר כפילות
- הטקסט לא נקרא ע"י גוגל ולא ע"י קורא מסך, ולכן חובה למלא `alt` לכל אייקון
  (השדה `heroIcons[].alt` בקובץ המוצר)
- הקבצים בפרופורציות שונות (183×243 עד 307×257), ולכן הם מנורמלים **לפי גובה**
  ולא ברוחב אחיד — אחרת הרחבים נראים קטנים יותר

מהמקור שונה רק צבע המילוי (`#078D60` → `#0B8F5A`). הצורות לא נגעו, כפי שהאפיון דורש.

## חברות שבחרו לעבוד איתנו

הבלוק מציג **שמות בלבד, ללא לוגואים**, לפי הנחיית הלקוחה: אין לפרסם לוגו של
חברה ללא אישורה. קבצי הלוגו שנאספו קודם הוסרו מהריפו.

כשיתקבלו אישורים, ההחלפה היא להוסיף קובץ ל-`assets/img/clients/` ולהחליף
`<span class="client__name">` ב-`<img class="client__logo">`. שימו לב שהלוגואים
מגיעים בפרופורציות שונות מאוד, ולכן צריך נרמול אופטי (גובה מותאם לכל סימן)
ולא גובה אחיד — אחרת סימן רחב ייראה קטן יותר מסימן גבוה.

## הוספת עמוד חדש

כל עמוד פנימי יושב בתיקייה משלו (`products/index.html` וכו') כדי שהכתובת תהיה
`/products/` — כמו שתהיה בוורדפרס. מתוך תיקייה כזו כל הנתיבים היחסיים מקבלים
`../` (למשל `../css/site.css`).

ה-Header, ה-Footer, טופס הפנייה וה-sprite של האייקונים זהים בכל העמודים.
**`index.html` הוא המקור** — אחרי שינוי באחד מהם מריצים:

```bash
python tools/sync-shell.py && python tools/build-products.py && python tools/build-product-pages.py
```

`sync-shell.py` מעתיק את ארבעת הבלוקים לשאר העמודים, מוסיף `../` לנתיבים לפי
עומק העמוד, ומעביר את `aria-current="page"` לפריט התפריט הנכון. עמוד חדש צריך
להתווסף לרשימת `TARGETS` שבראש הסקריפט.
