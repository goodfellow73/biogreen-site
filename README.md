# BioGreen — אתר סטטי

דף הבית של ביו-גרין, בנוי לפי:

- `מבנה דף הבית.docx` — המקור הקובע לתוכן ולסדר הבלוקים
- `BioGreen Design System.pdf` — הסקיצה, רפרנס לשפה הוויזואלית
- מערכת העיצוב שבתיקיית האב (`../tokens`, `../assets`, `../readme.md`)

התיקייה עצמאית לחלוטין — אפשר להעלות אותה כמו שהיא לכל שרת סטטי.

## מבנה

```
site/
├── index.html            דף הבית. כל הטקסטים בקובץ הזה.
├── css/
│   ├── design-system.css נקודת כניסה — מייבאת את שאר קבצי הטוקנים
│   ├── colors.css  typography.css  spacing.css  fonts.css  base.css  components.css
│   │                     העתק ממערכת העיצוב. לא לערוך ידנית.
│   └── site.css          פריסת הדף, הדר, פוטר, מודאל, רספונסיביות
├── js/
│   └── site.js           תפריט מובייל, אקורדיון, מודאל. ללא תלויות.
└── assets/
    ├── fonts/            Heebo, Assistant, Frank Ruhl Libre (woff2, self-hosted)
    ├── logo/
    └── img/              תמונות מוצר ורקעים, מוקטנות ומאופטמות לווב
```

האייקונים הם SVG sprite בתוך `index.html` (מקור: `../assets/icons`, Lucide).
שימוש: `<svg class="icon" width="20" height="20"><use href="#i-truck"></use></svg>`.

## הטופס

טופס אחד משרת את שלושת השערים. נפתח כמודאל, עם סוג הפנייה מסומן מראש:

- `<button data-quote data-intent="import|products|raw">` — פותח את הטופס על הסוג הזה
- `data-product="שם המוצר"` — ממלא מראש את שדה המוצר (כפתורי המוצרים עושים זאת)
- `?intent=import` בכתובת — פותח את הטופס בטעינת הדף, לקמפיינים ולינקים חיצוניים

שלב 4 בטופס מתחלף לפי סוג הפנייה (ספק כן/לא / מה מחפשים / איזה חומר גלם).

## מה עוד צריך להשלים

| נושא | איפה | מה חסר |
|------|------|--------|
| טלפון, וואטסאפ | `js/site.js` → `CONTACT` | המספרים האמיתיים. מוגדרים במקום אחד בלבד. |
| אימייל | `index.html`, פוטר | כרגע `info@biogreen.co.il` |
| שליחת הטופס | `js/site.js`, סוף הקובץ | חיבור ל-CRM או למייל. ה-payload כבר מוכן. |
| לוגואי לקוחות | בלוק 4 | כרגע wordmarks טקסטואליים. צריך קבצי לוגו. |
| תמונת Hero | `assets/img/hero-macro.jpg` | במסמך נכתב "נחליט בהמשך". |
| תמונת כורכומין 185 | `assets/img/product-curcumin-185.jpg` | המקור 300×300 בלבד — נראה רך. צריך צילום ברזולוציה גבוהה. |
| עמודים פנימיים | כל הקישורים ב-`index.html` | מצביעים לכתובות לפי ה-sitemap; העמודים עוד לא נבנו. |
| כתובת האתר | JSON-LD בתחתית `index.html` | `biogreen.co.il` — לעדכן אם שונה. |
